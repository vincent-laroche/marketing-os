# Social Template Catalog

The source-controlled template library contains 16 individual HTML templates. Open
`../templates/html/index.html` after running `npm run build:templates`.

## Feed

| Template | Use | Hard gate |
| --- | --- | --- |
| `hero-brand-post` | Brand or founder thesis | One idea and one supporting line |
| `single-product-post` | One product and one material detail | Live product and media verification |
| `collection-post` | Category or collection overview | Verified category and approved plates |
| `quote-testimonial-post` | Customer proof | Exact quote and exact-use written consent |
| `blog-article-post` | Education or guide | Factual content owner review |
| `sale-promo-post` | A rare verified promotion | Live offer, dates, scope, and exclusions |
| `announcement-post` | Launch or operational update | Live owner and effective date |

## Stories

| Template | Use | Hard gate |
| --- | --- | --- |
| `story-product` | One product and one useful detail | Approved vertical media and live product check |
| `story-quote` | Customer proof | Exact quote and exact-use written consent |
| `story-sale` | A rare verified promotion | Live offer and link target check |

## Carousels

| Template | Frames | Structure |
| --- | ---: | --- |
| `how-it-works` | 5 | Hook, three verified steps, next step |
| `before-after` | 3 | Matched before, process context, matched after |
| `drop-reveal` | 4 | Useful tease, two verified details, reveal |
| `testimonial-set` | 3 | Three independently sourced and consented quotes |

## Reels

| Template | Use | Hard gate |
| --- | --- | --- |
| `reel-cover` | 1080×1350 feed cover | Accurate promise and 320px legibility |
| `reel-storyboard` | Five-beat 1080×1920 plan | Approved source video, burned-in captions, safe zones |

The first carousel frame must work independently. Story and Reel key text stays outside the top and
bottom 250px and outside the outer 160px. No file in this catalog authorizes publishing or scheduling.
