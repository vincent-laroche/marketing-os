# Reference Routing

This folder intentionally contains routing notes, not copied brand files or screenshot libraries.

## Current authorities

Brand, logo, font, and platform-design authorities live outside this public repository in the approved local brand workspace. Resolve them at use time; do not treat a cached copy or an absolute local path in this repository as authority.

- Reusable Social template source: `../templates/`
- Canonical structural fixture: `../campaigns/schema-fixture/`
- Operational calendar and readiness owner: the Notion Content Production Board, read-only unless separately approved
- Public Social content classification: [`../../docs/social-media/PUBLIC-CONTENT-AUDIT.md`](../../docs/social-media/PUBLIC-CONTENT-AUDIT.md)

## What is not in this repository

Prior screenshot collections, generated mannequin images, generic social-ad examples, old template screenshots, and duplicate brand-authority files are outside this public repository. They do not control current design decisions and must not be reintroduced as a bulk inspiration dump.

## Adding a reference

Add only a small, source-attributed file that answers a current production question. Do not copy the brand master, logo directory, fonts, generated imagery, stock imagery, or a large inspiration dump into this repository. Customer proof and customer media require an exact source, rights review, and exact-use consent record outside this folder. Migrated historical/reference data remains quarantined under Issue #102 until individually classified.
