# Newsletter Programme

**One audience, five formats, biweekly. 20 editions ≈ 9–10 months of runway. The newsletter always loses the frequency-cap slot to journey emails.**

<aside>
🧮

**Audience formula — recomputed before every send, never a static list:** marketable + News & Offers − suppression lists − active Cart Recovery / Win-Back / J5 enrollees.

</aside>

## ⚙️ Operating rules

- **Cadence:** biweekly. If a journey email is due for a contact in the same window, the newsletter skips — the cap is 2 marketing emails per contact per 7 days, and journeys always win the slot.
- **Channel:** Marketing / News & Offers — the one programme a promo unsubscribe should remove you from. Active Cart Recovery, Win-Back and J5 enrollees are excluded by the audience formula, not by hand.
- **Rotation:** Education → Story → Offer → Brand → Launch, repeated four times. Each Education edition pairs with a blog post on the same topic for SEO reuse — the CTA lands on the post.
- **Copy depth:** **Full** = written completely now (evergreen). **Template** = complete module-by-module copy with token placeholders — real customers, launches and offers cannot be invented (brand rule), so those editions get filled when their slot arrives.

## 📊 KPI per format

| Format | KPI | What it tells you |
| --- | --- | --- |
| Education | Clicks to the paired blog post | Whether the content answers real questions |
| Story | Replies | Whether readers see themselves in it |
| Offer | Revenue | Whether the offer was worth interrupting for |
| Brand | Unsubscribe rate (trust signal) | A no-offer email should cost near-zero unsubscribes |
| Launch | Product-page sessions | Whether the positioning made people look |

## 📋 Fill checklist — reality-dependent editions (~20 min per edition when its slot arrives)

1. Pull proof from the Proof Bank — Permission = Yes only; relate the row via Used In
2. Replace every `{{ token }}`, `[PULL …]` and `[OFFER — confirm before send: …]` placeholder
3. Verify links + UTMs (Education → paired blog post; Offer → the exact collection)
4. Send a test
5. Schedule

## 🧱 Format stacks

`()` = non-negotiable · `[]` = recommended. A missing `()` family sets Build Status = Blocked - missing module.

| Format | Stack |
| --- | --- |
| Education | (Text - Masthead) (Text - Opening) (Column - Image and text) (Comparison or Text - Base type guidance) (FAQ) [Testimonial] (Button - Primary CTA → paired blog post) (Footer - Social) |
| Story | (Text - Masthead) (Photo - Feature story) (Text - Opening) (Quote - Centered) (Testimonial) [Review stars] [Stat bars] (Product - Dynamic recommendations) (Button - Primary CTA) (Footer - Social) |
| Offer | (Text - Masthead) (Text - Offer discount: hero position) (Signal - Promo code) (Signal - Countdown) (Grid - Collections 4) [Product - 3-up grid] [Testimonial] [List - Trust strip] (Button - Primary CTA → exact collection) (Footer - Standard) |
